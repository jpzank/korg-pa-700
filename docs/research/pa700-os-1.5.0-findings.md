# PA700 Operating System 1.5.0 — integration findings

## Source and boundary

The source inspected was the official `Pa700_Operating_System_v150.zip`. The
analysis was read-only: no updater script was executed, no package was installed
and no encrypted musical resource was decrypted. No proprietary firmware file is
stored in this repository.

The two update variants use the proprietary `KORG-SW6 / WorkHorse6` container
for product `Z111A`. They target different hardware families, but both expose the
same indexed musical resources and the same declared `Factory.BKP` digest. The
application therefore keeps one PA700 musical catalogue.

## USB MIDI identity

The firmware MIDI initialization script declares:

| Variant | USB vendor | USB product | Host source | Host destination |
| --- | ---: | ---: | --- | --- |
| PA700 | `0x0944` | `0x01C9` | `Pa700 _ KEYBOARD` | `Pa700 _ SOUND` |
| PA700 Oriental | `0x0944` | `0x01CB` | `Pa700 Oriental _ KEYBOARD` | `Pa700 Oriental _ SOUND` |

macOS has already exposed the Standard model as `Pa700 KEYBOARD` and
`Pa700 SOUND`, without the firmware underscore. These strings are transport
candidates only. The universal identity response remains the authoritative
instrument confirmation.

## User MIDI presets

The New Features documentation describes 16 user-overwritable MIDI preset
slots. Thirteen preset names are documented:

- Default
- Master Kbd
- Player
- Accordion 1
- Accordion 2
- Accordion 3
- Tablet
- Key Control
- Mix Control
- Pad Control
- X/Y Control
- Studio Ctrl
- Breath Ctrl

Documented purposes include remote SongBook selection for Tablet, volume and
pan for Mix Control, Upper 3 routing for Key Control, percussive/special Upper 3
plus arranger chords for Pad Control, and two Upper 1 parameters for X/Y Control.
The documentation does not expose enough bytes to promote any new CC, Program
Change or SysEx mapping. Arranger Lab continues to require its physically
verified `ArrangerLab` preset.

## Media inventory vocabulary

The package scripts recognize these resource extensions:

`MID`, `JBX`, `KMP`, `PAD`, `SBD`, `STY`, `PRF`, `VOC`, `GTR`, `PCG`, `TBL`,
`XML`, `FLAC`, `MD5`, `BKP` and `KAO`.

The canonical resource locations are:

- `GLOBAL`
- `GUITARPRESET`
- `KEYBOARDSET`
- `MULTISMP`
- `PAD`
- `SONGBOOK`
- `SONGBOOK/SONGDB.SBD`
- `SOUND`
- `STYLE`
- `SYSTEM`
- `SYSTEM/RESOURCEBROWSER`
- `VOICEPRESET`
- `KAOSSPRESET`

Arranger Lab uses this vocabulary only for a metadata inventory. The media
inspector does not install, edit, extract, convert or decrypt resources. A
recognized format is not the same thing as a decoded format or a Verified MIDI
mapping.
